# 4lpha Documentation

Standalone documentation site for the 4lpha Agent Marketplace.

[Live site](https://docs.4lpha.tech)

## Local development

The checked-in `index.html` is self-contained and can be opened directly.

```bash
npm install
npm run build
npm run preview
```

Preview: `http://127.0.0.1:4318`

- `explainer-src/` — source content and interactive explainers
- `build.mjs` — rebuilds `index.html`
- `preview.mjs` — local preview server
- `THIRD-PARTY-NOTICES.txt` — third-party asset notices

The docs are English-only and independent from the marketplace and execution applications.
